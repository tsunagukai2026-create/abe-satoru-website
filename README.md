# 安部達 公式ウェブサイト v2

配色を「生成り × 墨色 × 朱赤」に変更し、指定された4枚の写真を組み込みました。

## 配色
- 背景: #F3F0E8
- 白背景: #FCFBF7
- 文字: #252724
- 朱赤: #9E3D32
- 深緑: #536357
- 線: #CFC8B9

## 写真の掲載位置
- プロフィール: images/profile.jpg
- 日中関係史: images/nichichu.jpg
- 随筆: images/essay.jpg
- 未来へのバトンをつなぐ会: images/baton.jpg

## 編集
本文は `data/site.json` で編集できます。
CMSを使う場合は `admin/config.yml` の GitHub リポジトリ名を設定してください。
